## The entry

> I sneezed so hard this morning I pulled a muscle I didn't know existed, and now I walk like a folding chair.

Why it works: a sneeze injury is half-believable (a boss has heard stranger), it is a fresh idea instead of a fever, a dog, or a dead grandmother, the laugh lands on the very last words — the folding chair — and it reads like a real text to a boss, with no wasted words.

## How it works

`main.py` writes the excuse to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), enforcing the gate: UTF-8 text, 1–200 characters, a single line, no surrounding whitespace.

```sh
python3 main.py
```
